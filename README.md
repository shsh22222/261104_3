# 間 MA

**思考と思考のあいだへ。いまに在るための、静かなスマホアプリ。**

エックハルト・トールが語る「いま、この瞬間に在る（Presence）」という意識の状態で生きることを、日常の中で何度も思い出せるようにするための PWA（ホーム画面に追加して使うWebアプリ）です。iPhone でも Android でも同じように動き、オフラインでも開けます。

軸は**インナーボディ**（体の内側の、生き生きとしたエネルギーの感覚）と、それに伴う**呼吸**です。体の内側は、いつも「いま」にしかありません。

このアプリの設計は、3回の専門家会議から生まれました。

- [第1回: 教えと設計原則](docs/expert-council.md) ── 観想、神経科学、心理、行動デザイン、禅、俳句など10分野による水平思考の会議
- [第2回: 体験の設計（UI／UX）](docs/ux-council.md) ── UI・モーション・ゲーム・サウンド・映画編集などの専門家による、「指で伝える」体験の会議
- [第3回: インナーボディと呼吸を軸に](docs/innerbody-council.md) ── 呼吸生理学、ソマティック、気功、理学療法、ダンスなどの専門家による会議

> このアプリは月ではなく、月を指す指です。
> 指を見つめ続けさせたら失敗。指したら、すぐに消える。

---

## 体験の流れ

1. **開く** ── 時刻に合わせた光（夜明け・朝・昼・夕暮れ・夜）が、ホームの背後にそっとにじむ
2. **指を置く** ── 中心にあるのは、淡い人の形（インナーボディの図）。指を置いているあいだだけ周りが消え、選んだ入口（手・足・お腹・胸・全身）から内側の光がひろがり、呼吸とともに満ちて広がる
3. **一つだけ** ── 時間帯に合ったワークを一つだけ差し出す（朝は目覚めの体、昼は目を開けたまま、夕べは呼吸とともに、夜は眠る前に）
4. **目を上げて** ── すべての体験の最後は、毎回変わる具体的な知覚のひと言で画面の外を指す

## 設計の核

| 原則 | アプリでの形 |
|------|--------------|
| 開いた瞬間から、閉じる方向へ | すべての体験が「画面から目を上げて」で終わり、少しすると画面そのものが暗くなる |
| 最小単位は一呼吸 | ホームは呼吸の円が一つ。タップして10秒で終わる |
| 鐘は世界の中に置く | 手洗い・ドア・スマホを手に取る瞬間・季節・他者をアンカーにする |
| 記録は消えていく | 在った瞬間は夜空の星になり、7日かけて消える。データも本当に消える |
| 数えない、比べない、競わない | ストリーク、スコア、バッジ、ランキングは持たない |
| 揺れは材料 | イライラや焦りの瞬間のためのフロー。足の裏から始め、名づけ、体で感じ、見守る |
| 沈黙を設計する | BGMなし。鐘は合成した倍音が消えていく音 |
| 内面は端末の外に出さない | アカウントなし、解析なし、送信なし |
| 卒業できるアプリ | ミニマルモードでホームを円と問いだけにできる |

## 機能

| 画面 | 内容 | 対応する教え |
|------|------|--------------|
| いま（ホーム） | インナーボディの図に指を置く、今日の問い、いまのワーク一つ、今日の七十二候 | インナーボディ |
| 体の入口 `#body-entry` | 手・足・お腹・胸・全身から、感じやすい入口を選ぶ | インナーボディ |
| 呼吸とともに `#breathe-with` | 吸うあいだ指を置き、吐くあいだ離す。光が自分の呼吸で満ち、広がる。終わりに呼吸の変化を一文で返す | 呼吸、インナーボディ |
| 思考の雲 `#clouds` | 書いた思考が雲になって空を流れる。つかむと指についてくる。離せば流れていく。消すことはできない | 思考の観察、意識（空）と形（雲） |
| 一呼吸 `#breath` | 吸って4秒・吐いて6秒の、たった一つの呼吸 | 意識的な呼吸 |
| ワーク `#practice` | 軸のインナーボディ10種（手のいのち、体をめぐる、体が呼吸している、光の体、目を開けたまま、内側の静けさへ、目覚めの体、眠る前に、感情を体の中で、内側を感じながら聴く）と、思考・静けさ・受容・世界から入るワーク。インナーボディのワークでは図の光が段ごとの注意の場所を示す。声のガイド、目を閉じるモード付き | いまへの入口 |
| いま、揺れている `#sos` | イライラ・焦り・モヤモヤの中で。足裏 → 名づける → 体で感じる → 見守る → 三つの選択肢（離れる・変える・受け入れる） | ペインボディ、非抵抗 |
| 日常の鐘 `#anchors` | 毎日の行為から3つまでを選び、いまへの入口にする | 日常の行為を入口に |
| ゲート `#gate` | スマホでSNSなどを開く前の一呼吸。iPhoneのショートカットで自動化できる | 無意識の衝動に気づく |
| ランダムな鐘 `#bells` | ランダムな時刻の鐘をカレンダーファイル（.ics）として書き出す。開いている間だけ鳴らす方式も | 経験サンプリング |
| 鐘に応える `#bell` | 「その瞬間、どこにいましたか」。答えは裁かれない | メタ認知的な気づき |
| 今の一句 `#haiku` | 見たままを一行で。評価・心理的時間・物語の言葉にそっと気づかせる | 言葉の手前の知覚 |
| 作務 `#samu` | 皿洗いなどを始まりと終わりの鐘で区切る。受容・楽しみ・情熱から質を選ぶ | 目覚めた行為 |
| 今日を手放す `#evening` | 今日在った一瞬を一行書き、文字が崩れて消えていく | 無常、手放し |
| 夜空 `#sky` | 在った瞬間が星になり、日がたつと消える（「日常」の奥に控えめに） | 無常 |
| 教えの地図 `#learn` | いま、思考の観察、エゴ、ペインボディ、心理的時間、インナーボディ、受容、空間と静けさ、目覚めた行為、内なる目的、関係の中で | 全体の地図 |

## 使いはじめる

### スマホで使う（GitHub Pages）

1. このリポジトリの **Settings → Pages** で、Source を **GitHub Actions** にする。
2. `main` ブランチに取り込むと、`.github/workflows/pages.yml` が `app/` を公開する。
3. 公開されたURLをスマホで開き、ホーム画面に追加する。
   - iPhone: Safari の共有ボタン →「ホーム画面に追加」
   - Android: Chrome のメニュー →「ホーム画面に追加」または「アプリをインストール」

`app/` はビルド不要の静的ファイルなので、Netlify や Cloudflare Pages などに置いても動きます。

### 手元で動かす

```bash
npm start
```

`http://localhost:5173/` で開きます。依存パッケージはありません（Node.js 20 以上）。

## スマホを開く瞬間を、鐘にする（iPhone）

1. 「ショートカット」アプリ →「オートメーション」→ 新規 →「App」
2. つい開いてしまうアプリを選び、「開いている」にチェック、「すぐに実行」
3. アクション「URLを開く」に `公開したURL#gate` を入れる

アプリ用のURLスキームがわかる場合は `公開したURL?then=instagram://#gate` のように渡すと、ゲートの後に「続ける」ボタンでそのアプリへ戻れます（http/https 以外のスキームのみ受け付けます）。

## ランダムな鐘

PWA は、アプリを閉じている間に通知を鳴らすことができません。そこで、ランダムな時刻の鐘を**カレンダーの予定**として書き出し、端末のカレンダーに鳴らしてもらいます。サーバーも通知の許可も不要で、いつでもまとめて消せます。専用のカレンダー「間」を作ってから取り込むのがおすすめです。

## プライバシー

- データはすべて端末の `localStorage` にだけ保存されます。送信は一切ありません。
- 星（記録）は設定した日数（既定7日）で端末からも削除されます。
- 設定画面から、書き出し（JSON）とすべての消去ができます。

## 開発

```bash
npm test
```

純粋関数（季節の計算、鐘の時刻とカレンダー書き出し、評価語の検出、星の消え方）と、service worker のキャッシュ一覧の漏れを確認します。

```bash
npm run e2e
```

実ブラウザ（Playwright の Chromium）で、はじめの体験（指を置く）→ ホームで指を置く → 一呼吸 → ワーク → ゲート → 一句 → 鐘 → 揺れ → 思考の雲（雲をつかむ）→ 作務 → 手放し → 夜空 → 設定まで、すべての流れを偽の時計で早送りしながら動かします。引数にフォルダを渡すとスクリーンショットを保存します。

```bash
npm run build:preview
```

1ファイルにまとめたプレビュー版を `dist/preview.html` に作ります（claude.ai のアーティファクトで試すため）。

アイコンを作り直すときは `npm run icons`（Pillow が必要）。`app/` のファイルを追加・変更したら、`app/sw.js` の `VERSION` を上げてください。

### 構成

```
app/
  index.html            画面の骨格
  styles.css            デザイン（夜の藍墨と真鍮の鐘。朝のテーマは霧の青灰）
  sw.js                 オフライン用の service worker
  manifest.webmanifest
  icons/
  js/
    main.js             画面遷移
    store.js            端末内の保存
    audio.js            合成した鐘、読み上げ、振動、画面の点灯維持
    content.js          実践・問い・アンカー・教えの言葉
    lib/                純粋関数（テスト対象）
    views/              各画面
docs/expert-council.md  第1回 専門家会議（教えと設計原則）
docs/ux-council.md      第2回 専門家会議（体験の設計）
docs/innerbody-council.md 第3回 専門家会議（インナーボディと呼吸）
tests/                  単体テストと E2E テスト
scripts/                開発用サーバー、アイコン生成、プレビュー版の生成
```
