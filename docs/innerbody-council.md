# 第3回 専門家会議 ── インナーボディと呼吸を軸にする

> 議題: エックハルト・トールが重視するインナーボディ（体の内側の、生き生きとしたエネルギーの感覚）と、それに伴う呼吸を、このアプリの軸にする。実践の仕方にはバリエーションがある前提で、どう体感させ、どう日常に持ち出してもらうか。

---

## 1. 参加者（10名）

いずれも想定上の専門家で、実在の人物ではありません。

| # | 専門 | 役割 |
|---|------|------|
| 1 | 観想実践の指導者（第1・2回から続投） | トールの教えに忠実か |
| 2 | 認知神経科学者（内受容感覚、第1・2回から続投） | 体の内側への注意が、脳と体にどう働くか |
| 3 | 呼吸生理学の研究者 | 呼吸の速さと吐く息の長さ |
| 4 | ソマティック（身体感覚）実践の専門家 | 体の感覚から入る実践の作法 |
| 5 | 気功の指導者 | 「気感」と丹田、イメージの使い方 |
| 6 | 理学療法士 | 姿勢、触れること、日常動作 |
| 7 | ダンサー・振付家 | 内側から動く、動きながら感じる |
| 8 | モーションデザイナー（第2回から続投） | 光と動きで、見えない感覚を見せる |
| 9 | ハプティクスデザイナー（第2回から続投） | 振動と触覚 |
| 10 | UXストラテジスト（第2回から続投） | 動線と、日常への持ち出し方 |

---

## 2. 出発点

**観想実践の指導者**:「トールはインナーボディを、いまへの最も確かな入口の一つとして繰り返し語っています。思考は過去と未来へ出かけますが、体の内側の感覚は、いまにしか存在できない。だから注意の一部を体の内側に置いておくことが、いまに根を下ろす錨になる。手の内側の生きている感じから始めて、全身をひとつの場として感じ、さらにその奥の静けさへ。日常の中でも、話しながら、聴きながら、少しだけ内側に居続ける。この流れが軸です。」

**認知神経科学者**:「体の内側の状態を感じ取る力は内受容感覚と呼ばれ、訓練で変化しうることが知られています。手のように感覚の解像度が高い場所は入口に向いています。ただ、感じやすい場所には個人差がある。」

**UXストラテジスト**:「目に見えない感覚を、アプリの画面でどう扱うか。ここが今回の勝負です。」

---

## 3. 議論と決定

### 3-1. 見えない感覚を、光で見せる

**モーションデザイナー**:「人の形をした、ほとんど見えないくらい淡いシルエットを置きます。体を“外から”描くのではなく、内側の光だけが主役。注意を置く場所が、やわらかく光る。」

**ソマティック実践の専門家**:「大事なのは、図が“正解の感覚”を押しつけないことです。光は『ここに注意を置く』という案内であって、『こう感じるべき』ではない。」

**気功の指導者**:「気功でも、最初はイメージを借ります。光が手のひらにある、と思うと感じやすくなる人は多い。ただし、最後はイメージを手放して、感じだけを残す。」

**決定**: インナーボディの図（淡い人の形と、内側の光）を、ホームの中心とワークの画面に置く。光は「注意の場所」を示すだけで、感じ方は指示しない。

### 3-2. 入口は人によって違う

**理学療法士**:「手が感じやすい人もいれば、足の裏のほうが感じやすい人もいる。胸は感情と結びつきやすいので、繊細な人には強すぎることもある。」

**認知神経科学者**:「入口を選べるようにすれば、最初の10秒の手応えが変わります。」

**決定**: 「体の入口」を、手・足・お腹・胸・全身から選べる。ホームで指を置くと、選んだ入口から光が始まり、全身へひろがる。日によって変えてよいことを明記する。

### 3-3. 呼吸は「整える」のか「感じる」のか

**呼吸生理学の研究者**:「吐く息を吸う息より長くすると、体は落ち着く方向へ向かいやすい。1分に6回前後のゆっくりした呼吸も、よく研究されています。」

**観想実践の指導者**:「一方で、トールが勧めるのは呼吸の操作ではなく、呼吸に気づくことです。体が呼吸しているのを、内側から感じる。」

**ダンサー**:「両方あっていい。ただ、主役を“感じる”ほうに。リズムを外から与えるのは、指を置くときの小さな拍だけで十分です。」

**ハプティクスデザイナー**:「そこで逆転の発想を。アプリが呼吸を導くのではなく、**利用者の呼吸にアプリがついていく**。吸うあいだ指を置き、吐くあいだ離す。図の光は、その人自身の呼吸で満ち、広がる。」

**UXストラテジスト**:「終わりに、数字ではなく一文だけ返す。『呼吸が、ひとりでにゆっくりになっていきました。あなたが何かをしたのではなく、体がそうしたのです。』」

**決定**:
- 新しいワーク「呼吸とともに」: 吸うあいだ指を置き、吐くあいだ離す。光がその人の呼吸に合わせて満ち、広がる。終わりに、呼吸の変化を一文で返す（回数や数値は出さない）
- 「体が呼吸している」: 呼吸を変えず、内側から感じるワーク
- 指を置くときの拍は、設定で「ゆったり（4・6秒）」「さらにゆっくり（5・7秒）」「均等（5・5秒）」から選べる

### 3-4. 実践のバリエーション

**気功の指導者**と**ソマティック実践の専門家**が中心になり、入口・深さ・場面でバリエーションを整理しました。

| ワーク | 位置づけ | 時間 |
|--------|----------|------|
| 手のいのち | はじまり。手の内側から | 1分 |
| 体をめぐる | 手から足へ、そして全身へ | 3分 |
| 体が呼吸している | 呼吸を変えず、内側から感じる | 2分 |
| 呼吸とともに | 自分の呼吸に指と光がついていく | 2分 |
| 光の体 | 感じにくい日に、イメージを入口に | 2分 |
| 目を開けたまま | 内側に根を下ろして、世界を見る・歩く | 1分 |
| 内側の静けさへ | エネルギーの場の、さらに奥へ | 3分 |
| 目覚めの体 | 起き上がる前の1分 | 1分 |
| 眠る前に | 今日を手放し、体の内側へ | 3分 |
| 感情を、体の中で | 物語ではなく、エネルギーとして | 2分 |
| 内側を感じながら聴く | 会話の前に | 1分 |

ほかの入口（思考、静けさ、受容など）のワークにも、体の内側に戻る段を加え、すべてがインナーボディに還ってくる構成にしました。

### 3-5. 日常へ持ち出す

**ダンサー**:「インナーボディの本番は、座っている時間ではなく、動いている時間です。」

**理学療法士**:「日常の鐘（アンカー）を、すべて体の内側とつなげましょう。手を洗うとき、水の温度と手の内側を同時に感じる。階段で、脚の内側を感じる。」

**UXストラテジスト**:「体験の最後のひと言も同じです。『目を上げて』だけでなく、『体の内側を感じたまま、いちばん遠くの音を一つ聴く』。内側に根を下ろしたまま、外の世界へ。」

**決定**: 日常の鐘12項目と、終わりのひと言をすべて「内側を感じたまま」の形に書き換える。時間帯ごとのワークも、朝は目覚めの体、昼は目を開けたまま、夕べは呼吸とともに、夜は眠る前に、とする。

---

## 4. 採用しなかったアイデア

| アイデア | 理由 |
|----------|------|
| 心拍センサーやカメラで呼吸を計測する | 数値が目標になる。感じる主体が、機械に移ってしまう |
| 解剖学的にリアルな人体図 | 体を“外から見る対象”にしてしまう。内側の感覚から遠ざかる |
| 感じた場所を毎回記録してグラフにする | 蓄積の発想。感じ方の比較が始まる |
| チャクラなど特定の体系の図 | トールの教えの範囲を超え、体系の学習になる |
| 常時鳴る呼吸ガイド音 | 静けさを埋める |

---

## 5. 今回の変更

- ホームの中心を、インナーボディの図に（選んだ入口が静かに光って待っている）
- 指を置くと、入口から光がひろがり、呼吸とともに満ちて広がる。言葉も入口に合わせて変わる
- 「体の入口」を選べる（手・足・お腹・胸・全身）
- 新しいワーク「呼吸とともに」「手のいのち」「体が呼吸している」「光の体」「目を開けたまま」「内側の静けさへ」「目覚めの体」
- インナーボディのワークでは、図の光が段ごとの注意の場所を示し、呼吸の段では呼吸とともに満ちる
- 呼吸の速さを選べる（ゆったり／さらにゆっくり／均等）
- 日常の鐘と、体験の終わりのひと言を、すべて「体の内側を感じたまま」の形に
- 教えの地図の先頭に、インナーボディの詳しい解説
- はじめの体験を「手の内側に、何か感じましたか」で終える
