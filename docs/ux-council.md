# 第2回 専門家会議 ── 体験の設計（UI／UX）

> 議題: 「間」を、スマホの中の他のアプリに負けない魅力的な体験にする。
> ただし、記録の蓄積やストリークで呼び戻すのではなく、**ワークの動線**と、**エックハルト・トールの“感覚”そのものを手で伝えること**で、楽しんで使ってもらう。
>
> 前提の変更: プロダクトオーナーの判断により、対象は「日常の中でいまに在りたい人」と再定義した。強い苦痛の中にいる人の支援を目的とするアプリではないため、相談窓口などの案内は削除する。

---

|---|------|------------------|

| 2 | インタラクション・モーションデザイナー | 動きの質、触れたときの手応え |
| 3 | UXストラテジスト（オンボーディングと継続利用） | なぜまた開くのか、の設計 |

## 2. 問題の再定義

**UXストラテジスト**:「他のアプリは、通知、新着、連続記録、他者の反応で人を呼び戻します。そこで勝負をしたら負けるし、勝ってはいけない。このアプリが勝てる場所は一つだけです。**開いて10秒以内に、体がふっと緩む**こと。その感覚が報酬なら、人はまた来ます。」

**ゲームデザイナー**:「良い体験型のゲームは、遊び方を文章で説明しません。操作そのものが意味になっている。歩くこと、触れること、待つこと。このアプリも、トールの教えを“読ませる”のではなく、**指で体験させる**べきです。」

**観想実践の指導者**:「トールの感覚の核は、二つの気づきです。一つは、思考は“起きているもの”であって“私”ではないということ。もう一つは、その思考に気づいている、静かな空間のような意識があるということ。形と、空間です。これを体で感じられたら、言葉はほとんど要りません。」

ここから、会議の問いは次の三つに絞られました。

1. **最初の10秒で、何を感じてもらうか**（体感の報酬）
2. **開いてから閉じるまで、どう流れるか**（ワークの動線）
3. **トールの感覚を、どんな身ぶりと絵で伝えるか**（体験の言語）

---

## 3. 議論

### 3-1. 一つの身ぶり ──「指を置く」

**モバイルUIデザイナー**:「スマホでの操作は、ほぼすべて“何かをする”ためのものです。タップ、スワイプ、スクロール。逆に、**何もしないための操作**を一つだけ作りませんか。円に指を置いて、そのままにする。それだけ。」

**インスタレーション作家**:「指を置いているあいだだけ、世界が静かになる。画面の他の要素は消え、円だけが呼吸する。離すと、世界が戻ってくる。体験している人が、作品のスイッチそのものになるんです。」

**認知神経科学者**:「指先の触覚は、内受容感覚と外の世界の境目にあります。指を置いて静止する、という行為自体が身体への注意を呼びます。トールの言うインナーボディへの入口として理にかなっています。しかも、押し続けるには注意が要る。注意がそれれば指も緩む。」

**観想実践の指導者**:「“何もしない”をするボタン。教えに忠実です。何かを得るために押すのではなく、ただ在るために置く。」

**サウンド＆ハプティクスデザイナー**:「入るときに小さな鐘を一つ。呼吸に合わせて、吸うたびにかすかな振動（対応端末のみ）。離すときにもう一度だけ鐘。音楽は鳴らさない。」

**決定**: ホームの円は**長押しの身ぶり**を中心にする。指を置くと周りが消え、円が4秒吸って6秒吐く呼吸で動き、言葉が間をおいて一つずつ現れる。短いタップには「指を置いたまま、待ってみてください」とだけ返す。

### 3-2. 体験の終わりは、いつも外を指す

**映画編集者**:「映画は最後のカットで決まります。今の終わり方は『おかえりなさい』と言って止まる。でも本当に見てほしいのは画面の外です。**最後のカットを、画面の外に置く**べきです。」

**タイポグラファー**:「『目を上げて。』と大きく一行。その下に、具体的な一つだけの指示。『いちばん遠くの音を、一つ聴いてみる』『光が当たっているところを、一つ見つける』。抽象的な教えより、具体的な一つの知覚のほうが、いまに連れていきます。」

**観想実践の指導者**:「トールは、知覚を思考の解説なしに受け取ることを繰り返し勧めています。具体的な一つの知覚の指示は、教えの実践そのものです。」

**決定**: すべての体験の終わりに「外へのひと言」を添える。毎回ランダムで、同じ体験でも終わりが少しずつ違う（反復しても慣れにくい）。

### 3-3. 思考を“見る”を、絵にする ──「思考の雲」

**ゲームデザイナー**:「『思考を観察しなさい』と言われても、多くの人はどうしていいかわかりません。思考を**画面の上に流してしまえばいい**。いま頭にある言葉を一言ずつ書くと、それが雲になって空を流れていく。」

**インスタレーション作家**:「大事なのは、雲を消すボタンを作らないことです。潰したり、弾いたりできたら、ただのゲームになる。触れると、雲は指についてくる。**つかまえると、ついていってしまう**。手を離せば、また流れていく。それが、思考と同一化することの体感になります。」

**観想実践の指導者**:「完璧です。思考と戦わない。追いかけない。そして最後に、雲がいなくなっても空は空のまま、と気づく。空がトールの言う意識、雲が形です。」

**認知神経科学者**:「書き出す行為自体に、思考から距離を取る効果があります（脱フュージョン）。それを動きで見せるのは、理解ではなく体験として残りやすい。」

**モーションデザイナー**:「雲は下から上へ、ゆっくり。速さも大きさも少しずつ違う。後半ほど雲の数を減らして、空の割合を増やす。最後の30秒は、ほとんど空だけ。」

**決定**: 新しいワーク「思考の雲」を、このアプリの看板にする。約2分。

### 3-4. 動線 ── 開く、着地する、一つだけ、外へ

**UXストラテジスト**:「メニューが多いアプリは、開いた瞬間に『何をしようか』という思考を生みます。それこそが、このアプリが静めたいものです。ホームは**次の一つだけ**を差し出すべきです。」

**モバイルUIデザイナー**:「動線は四拍子にしましょう。

1. **開く** ── 時間帯に合わせた空の色が、そっと迎える
2. **着地する** ── 円に指を置く（10秒でも1分でも）
3. **一つだけ** ── いまの時間帯に合ったワークを一つ（朝は思考の雲、昼は作務、夕べは手放し、夜は眠る前）
4. **外へ** ── 目を上げて、具体的な知覚を一つ

迷ったら、1と2と4だけでいい。」

**映画編集者**:「場面転換には“間”を。要素が一気に出るのではなく、少しずつ現れて、少しずつ消える。」

**決定**: ホームは「空の色 → 円 → 今日の問い → いまのワーク一つ」の順に。ほかの入口は小さく控えめに。

### 3-5. 「いま」は画面の色にも

**インスタレーション作家**:「アプリの色が、実際の“いま”に合わせて変わったら？ 夜明けには薄い朱、昼は淡い青、夕暮れは琥珀、夜は藍。開くたびに、外の時間と同じ光がそこにある。」

**タイポグラファー**:「主張はしない。円の背後に、ほのかに光る程度で。」

**決定**: ホームの背景に、時刻に応じた光をにじませる。テーマ（夜／朝）とは独立して、どちらでも馴染む透明度で。

### 3-6. はじめの30秒は、説明ではなく体験

**ゲームデザイナー**:「最初の案内で三枚のスライドを読ませるのは、教科書を開かせるのと同じです。最初の画面は『指を、円の上に置いてください』だけ。」

**UXストラテジスト**:「そして離したときに、初めて言葉を渡す。『いま、少し静かになりましたか。その静けさが、このアプリのすべてです。』体験の後の言葉は、前の言葉の何倍も届きます。」

**決定**: オンボーディングを、説明スライドから「指を置く」体験そのものに置き換える。

### 3-7. 記録の扱い

**UXストラテジスト**:「夜空はきれいですが、タブとして並んでいると“集めるもの”に見えます。」

**観想実践の指導者**:「蓄積の発想は外したい。」

**決定**: 夜空は下のタブから外し、「日常」の奥にそっと置く。数も見せない。タブは「いま」「ワーク」「日常」の三つにする。

## 4. 対立と統合

| 対立 | 主張A | 主張B | 統合 |
|------|-------|-------|------|
| 楽しさ vs 静けさ | 4: 手応えがなければ戻ってこない | 9: 刺激はいまから遠ざける | 楽しさを「刺激」ではなく「体が緩む手応え」に置く。動きは遅く、音は少なく、終わりは外へ |
| 発見 vs 単純さ | 3: 新しさがないと飽きる | 1: 機能が増えると迷う | 新しさは毎回変わる「外へのひと言」「空の色」「雲の流れ」など、体験の質の中に置く。機能は増やさない |
| 触れる vs 触れない | 7: 雲に触れられるべき | 4: 触れられると遊んでしまう | 触れられるが、消せない。つかむと指についてきて、離すと流れていく。触れることが教えになる |
| 言葉 vs 体験 | 9: 教えは言葉で正確に | 4・8: 体験の前に言葉はいらない | 体験の前は最小限、体験の後に一言。詳しい言葉は「教えの地図」に |

## 5. 採用しなかったアイデア

| アイデア | 理由 |
|----------|------|
| 雲を指で弾いて消す | 思考を排除する操作になり、教えと逆。ゲーム化する |
| 長押しの時間を表示する | 時間が目標になり、エゴの比較が始まる |
| 毎日の新着コンテンツ | 「見逃したくない」という未来への執着を生む |
| AIの声による対話ガイド | 言葉が増え、画面に留める |
| 環境音・自然音のループ | 静けさを埋める（第1回の原則を維持） |
| ARで現実に雲を重ねる | 世界を見るはずが、画面越しに世界を見ることになる |

## 6. 体験の言語（このアプリの絵と身ぶり）

| 要素 | 意味 | 使い方 |
|------|------|--------|
| 円 | 在ること、意識 | ホームの中心。指を置く場所 |
| 指を置く | 何もしないこと | 唯一の“何もしない”操作 |
| 雲 | 思考（形） | 現れて、流れて、去る。消せない |
| 空 | 気づいている意識（空間） | 雲の背景。最後に残るもの |
| 鐘 | 呼びかけ | 入るときと出るときの一打だけ |
| 光の色 | 実際の“いま” | 時刻とともに変わる |
| 目を上げて | 世界へ還る | すべての体験の最後のカット |

## 7. 今回の変更

- 相談窓口などの案内を削除（対象の再定義による）
- ホームの円を「指を置く」長押しの体験に変更。周りが消え、呼吸する円と言葉だけが残る
- 体験の終わりに「目を上げて」と、毎回変わる具体的な知覚のひと言
- 新しいワーク「思考の雲」（書いた思考が雲になって流れる。つかむとついてくる）
- ホームを「空の色 → 円 → 問い → いまのワーク一つ」の動線に整理。朝のワークは思考の雲
- 時刻に応じた光をホームの背景に
- オンボーディングを、説明スライドから「指を置く」体験に変更
- タブを「いま」「ワーク」「日常」の三つに。夜空は「日常」の奥へ

## 8. 体験の指標（設計目標）

| 指標 | 目標 |
|------|------|
| 開いてから、体が緩む最初の瞬間まで | 10秒以内（指を置くだけで届く） |
| ホームで「何をしよう」と迷う時間 | ほぼゼロ（差し出すのは一つだけ） |
| 体験の終わりに画面の外を見る | すべての体験で、最後のカットが外を指す |
